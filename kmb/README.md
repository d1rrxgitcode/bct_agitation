# KMB Dashboard

Локальный дашборд статистики агитаций на Node.js и SQLite.

## Требования

- Node.js 22.5 или новее
- встроенный модуль `node:sqlite`

## Запуск

```powershell
npm start
```

После запуска откройте `http://localhost:3000`.

При первом запуске существующие данные из `data/db.json` автоматически импортируются в `data/kmb.sqlite`. После миграции рабочей базой является SQLite-файл.

## Проверка API

```powershell
npm test
```

Проверка запускает сервер на временном порту и проверяет чтение данных, редактирование, валидацию и защиту связанных записей.
