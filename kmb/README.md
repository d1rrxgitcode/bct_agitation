# KMB Dashboard

Локальный дашборд статистики агитаций на Node.js и SQLite.

## Требования

- Node.js 22.5 или новее
- встроенный модуль `node:sqlite`

## Запуск

```powershell
npm start
```

После запуска откройте `http://localhost:3000`.

При первом запуске существующие данные из `data/db.json` автоматически импортируются в `data/kmb.sqlite`. После миграции рабочей базой является SQLite-файл.

## Разделы

- **КМБ и Агитации** — текущий дашборд, бойцы, кадеты, агитации и проверка дублей по IDN или позывному.
- **Формирования** — карточки с КМД/командиром, несколькими Зам КМД, текстовым агитлистом, внутренними подразделениями и составом.
- **Составы** — фильтр по формированию, подразделению и должности; создание подразделений и участников со званием, должностью, позывным, датой повышения и специализациями.
- **Документация** — создание категорий и карточек документов со ссылками на Google Docs или Google Drive, фильтр по категории и поиск по названию/описанию.

## Проверка API

```powershell
npm test
```

Проверка запускает сервер на временном порту и проверяет чтение данных, редактирование, валидацию и защиту связанных записей.
